# Project 02: Web Application Security Assessment (OWASP Juice Shop)

This directory contains the methodology, proxy inspection notes, and technical findings from an authorized web application vulnerability assessment against the **OWASP Juice Shop** environment.

* **Detailed Report:** View the full assessment in [reports/JuiceShop_Assessment_Report.md](./reports/JuiceShop_Assessment_Report.md)
* **Core Tools:** Burp Suite, Docker, HTTP Traffic Interception
* **Key Focus:** SQL Injection, Endpoint Reconnaissance (`robots.txt`), and Input Validation Analysis.
