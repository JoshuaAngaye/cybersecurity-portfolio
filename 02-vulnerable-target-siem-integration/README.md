# Project 02: Vulnerable Target SIEM Integration (Metasploitable 2)

This directory contains documentation and technical case studies regarding the deployment of a Wazuh agent onto an intentionally vulnerable 32-bit target (`Metasploitable 2`) to extend centralized log telemetry from the Project 01 SIEM deployment.

* **Detailed Case Study:** Read the full report in [reports/Metasploitable2_Agent_Integration_Case_Study.md](reports/Metasploitable2_Agent_Integration_Case_Study.md)
* **Core Technologies:** Wazuh SIEM, Metasploitable 2, Ubuntu 8.04, SCP, VMware Workstation NAT, SSH Administration.
* **Professional Alignment:** Mirrors enterprise endpoint integration challenges and manual configuration workflows observed during my cybersecurity internship at UNICCON Group of Companies.
